Projeto Raízes do Nordeste
Este repositório contém a documentação técnica e os protótipos de interface para a rede de alimentação Raízes do Nordeste. O objetivo central foi desenvolver uma solução multicanal que modernize o atendimento ao cliente, mantendo a identidade regional da marca.

📌 Visão Geral
O projeto foca na experiência do usuário (UX) através de uma abordagem Mobile-First, garantindo que a interface seja intuitiva tanto no uso pessoal (App) quanto no autoatendimento físico (Totem).

📂 Organização do Repositório
/documentacao: Contém o arquivo PDF final com o levantamento de requisitos, diagramas UML e plano de testes.

/documentacao/imagens: Repositório dos wireframes (versão mobile e tablet) e diagramas de processo.

🛠️ Metodologia e Ferramentas
Design de Interface: Figma (Prototipação de baixa e média fidelidade).

Modelagem: Draw.io para Diagramas de Caso de Uso e Jornada do Usuário.

Privacidade: Estrutura baseada nos princípios de Privacy by Design para conformidade com a LGPD.

⚙️ Nota sobre Implementação
Nesta etapa final, o foco foi restrito à arquitetura de informação, design de interface e planejamento de testes. A implementação do código-fonte e a versão Web completa utilizam os wireframes aqui apresentados como base responsiva.
